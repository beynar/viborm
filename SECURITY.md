# Security Policy

## Supported versions

Security fixes are released for the latest stable VibORM major. Before V1,
only the latest published release candidate is supported.

## Report a vulnerability

Use GitHub private vulnerability reporting for suspected security defects:

https://github.com/beynar/viborm/security/advisories/new

Do not open a public issue until the vulnerability has been assessed. Include
the affected VibORM version, provider, reproduction, and expected impact. We
will acknowledge a complete report and coordinate disclosure through the
private advisory.
