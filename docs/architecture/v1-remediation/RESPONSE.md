## Repairs that matter

- **Values and lifetimes:** supplied clients retain their ownership; failed cleanup quarantines the exact handle; failed transactions retain their primary error and rollback-only state. Integer, Decimal, temporal, JSON, and vector crossings preserve their admitted domains or refuse a lossy result with a specific error. Rejected async validators cannot leak unhandled rejections.
- **Query and cache behavior:** corrected join-fan-out counts, nested-write selection and ordering, PostgreSQL lock-wait predicate rechecks, skipDuplicates admission, updatedAt behavior, and scope isolation. Automatic cache invalidation clears the bound namespace, including relation reads; manual prefixes and explicit opt-out retain their separate contracts.
- **Statement dispatch:** fallback planning no longer calls transforms twice. Sequential batches finish every transform inside its statement observation before the first batch statement is dispatched, so a later handler cannot invalidate an earlier SQLite storage guard. Separate statement completion, logging, diagnostics, and rollback evidence remain intact.
- **Migrations:** managed scope, physical constraint identity, decimal/temporal storage, enum transitions, and advisory locks have concrete regression coverage. PostgreSQL rename planning now follows the same default-PK rule as its DDL and inverse, including bounded long names. Enum alteration runs after the table/column renames it consumes and keeps renamed array/default metadata. Unsupported physical objects receive explicit refusals before effects.
- **Public integration:** installed-package checks exercise value exports, optional-peer absence, CommonJS, driver setup, CLI configuration, extension recipes, and emitted declarations. Validation errors identify their path; provider details and caller locations require explicit disclosure. The CLI `.env` witness now supplies its own fixture instead of depending on a developer’s ignored file.

## Cyclic declarations and backend decision

Unannotated exported clients and client factories now preserve cyclic relation typing. At client construction, the type layer captures exact schema-key links while getter types are available, emits a flat model state plus a type-only link table, and restores target types through the linked client view. Runtime models and topology remain unchanged. Core and all eleven driver factories carry this representation; callers need no annotations or code generation.

The checks preserve valid and invalid IDs, fresh and held ordinary nested-WHERE field typos, exact result domains, missing-field rejection, modifiers, compound keys, omit, extensions, transactions, self-relations, both variant cardinalities, and literal target identity. **Rebuilding a client solely from already-emitted cyclic models remains lossy.** Arnaud explicitly accepted that boundary; it has source-valid and emitted-semantic negative controls, rather than a false success claim.

The current JavaScript declaration backend stays. Native direct emission and the isolated native bundler experiment also preserve the corrected client. The stock native plugin lacks its expected optional peer; OXC requires annotations for these inferred exports. Neither is presented as a qualified replacement. The [backend report](declaration-backends.md) separates compiler CLI support from JavaScript Compiler API tooling and library emission from application emission.

## A fresh roast

VibORM promised zero codegen, then invoiced the TypeScript compiler for the work. The compiler initially paid by emitting a declaration that forgot which model a relation pointed to. That is an impressive interpretation of “type-safe”: the package was safe from being used.

The test estate could litigate ownership of a result array, yet several fixtures still confused insertion order with a contract. One protected storage check ran before the handler that changed the storage. One migration knew the table’s new name while its scheduler still believed in the old timetable. These are ordinary bugs wearing unusually elaborate architectural uniforms.

The rigor now earns its keep where public queries, installed packages, and real providers can contradict the implementation. Keep that pressure. The next useful boast is a stranger shipping an application without learning the constitution first.
