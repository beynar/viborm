## Checkpoint laws

- Keep the public client route, operation names, schemas, driver API, and
  transaction API unchanged. Validate each public value once at its existing
  admission boundary; internal command values remain trusted.
- Extend the broad `OperationContext`, ordinary recursive command construction,
  and composed semantic owners. Do not add another interpreter, transaction
  protocol, framework, or speculative `memberPath` refactor.
- A prep slice is the smallest executable proof of ownership. It is not a claim
  that its inventory row, G3, G4, or the future recursive-read feature is
  complete.
- Historical evidence is immutable. Each unit freezes its own source and
  evidence identity. Validation runs serially on a stable snapshot.
- Across preparation, two repairs of the same failure or two language redesign
  rounds exhaust the budget and pause advancement for a decision.
