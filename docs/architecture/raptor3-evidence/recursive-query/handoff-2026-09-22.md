## Scope facts to preserve

- Self ordinary resolved relations with complete primary keys only: FK owning,
  inverse proven one-to-one, child-held collection, paired junction graph.
- `true`/`{}`/undefined depth normalize to 100; numeric depth 1–1000;
  `depth:false` exhaustive. `recurse:undefined` is absent; `recurse:false` invalid.
- FK has no public `preventCycles`; graph defaults to prevention, with false
  permitted only for bounded/default depth.
- Collection filters prune every hop; SQL owns per-parent ordering and key ties.
- Outer relation key is present; repeated key is absent at numeric cutoff;
  natural end before cutoff is [] or permitted null. No extra hop past cutoff.
- Root seeds the active path. FK cycle in-window errors; graph prevention is
  path-local, never global deduplication. Distinct paths have fresh occurrences.
- Full ordinary node projection repeats, including other ordinary/recursive
  slots and supported codecs. Asking key explicitly repeated inside its own
  projection is rejected at admission.
- Eligible find verbs and single-row create/update/upsert/delete relation
  results are in scope. Bulk selections remain scalar-only; count/exist/
  aggregate/groupBy do not gain recursion.
- One projected read statement regardless of data depth; mutations preserve
  ordinary pre-delete/post-write lifecycle, transaction authority and progress.
- No new engine, public CTE API, recursive mutation language, driver flag,
  per-depth/per-root queries, retry or provider-limit manipulation.
- Cache/default omit/extensions/arrays/schema-only rendering are required scope,
  not optional follow-up. Remote hosted qualification remains deferred.
