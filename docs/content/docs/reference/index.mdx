### Client

| API | Description |
|-----|-------------|
| `findMany` | Find multiple records |
| `findFirst` | Find first matching |
| `findFirstOrThrow` | Find first or throw |
| `findUnique` | Find by unique ID |
| `findUniqueOrThrow` | Find by unique ID or throw |
| `exist` | Check whether any row matches |
| `create` | Create record |
| `createMany` | Create multiple |
| `createManyAndReturn` | Create multiple, return rows |
| `update` | Update record |
| `updateMany` | Update multiple |
| `updateManyAndReturn` | Update multiple, return rows |
| `delete` | Delete record |
| `deleteMany` | Delete multiple |
| `upsert` | Create or update |
| `count` | Count records |
| `aggregate` | Run aggregations |
| `groupBy` | Group and aggregate |
