This is a quick index of VibORM's Prisma-inspired client API. Each operation has a dedicated page with full argument and return-type documentation. See [Compatibility](/docs/client/compatibility) for intentional differences from Prisma.

## Operations

| Operation | Signature | Returns | Docs |
|-----------|-----------|---------|------|
| `findMany` | `findMany({ where?, orderBy?, take?, skip?, cursor?, select?, include?, distinct? })` | `T[]` | [findMany](/docs/client/find-many) |
| `findFirst` | `findFirst({ where?, orderBy?, take?, skip?, cursor?, select?, include? })` | `T \| null` | [findFirst](/docs/client/find-first) |
| `findFirstOrThrow` | Same as `findFirst`, throws `NotFoundError` if no match | `T` | [findFirst](/docs/client/find-first) |
| `findUnique` | `findUnique({ where, select?, include? })` | `T \| null` | [findUnique](/docs/client/find-unique) |
| `findUniqueOrThrow` | Same as `findUnique`, throws `NotFoundError` if no match | `T` | [findUnique](/docs/client/find-unique) |
| `exist` | `exist({ where? })` | `boolean` | [exist](/docs/client/exist) |
| `count` | `count({ where?, select? })` | `number` or per-field counts | [count](/docs/client/count) |
| `aggregate` | `aggregate({ where?, _count?, _avg?, _sum?, _min?, _max? })` | Aggregate result object | [aggregate](/docs/client/aggregate) |
| `groupBy` | `groupBy({ by, where?, having?, orderBy?, take?, skip?, _count?, ... })` | Array of groups | [groupBy](/docs/client/group-by) |
| `create` | `create({ data, select?, include? })` | `T` | [create](/docs/client/create) |
| `createMany` | `createMany({ data, skipDuplicates? })` | `{ count: number }` | [createMany](/docs/client/create-many) |
| `createManyAndReturn` | `createManyAndReturn({ data, skipDuplicates?, select? })` | `T[]` | [createManyAndReturn](/docs/client/create-many#createmanyandreturn) |
| `update` | `update({ where, data, select?, include? })` | `T` | [update](/docs/client/update) |
| `updateMany` | `updateMany({ where?, data })` | `{ count: number }` | [updateMany](/docs/client/update-many) |
| `updateManyAndReturn` | `updateManyAndReturn({ where?, data, select? })` | `T[]` | [updateManyAndReturn](/docs/client/update-many#updatemanyandreturn) |
| `upsert` | `upsert({ where, create, update, select?, include? })` | `T` | [upsert](/docs/client/upsert) |
| `delete` | `delete({ where, select?, include? })` | `T` | [delete](/docs/client/delete) |
| `deleteMany` | `deleteMany({ where? })` | `{ count: number }` | [deleteMany](/docs/client/delete-many) |

`exist` is a VibORM extension. Prisma has no direct `exist` operation, and VibORM does not expose an `exists` alias.

## Ordering

```ts
orderBy: {
  field: "asc" | "desc",
  // or
  field: { sort: "asc" | "desc", nulls: "first" | "last" },
  // or relation
  relation: { field: "asc" | "desc" },
  // or count
  relation: { _count: "asc" | "desc" },
  // or vector distance (vector fields only)
  embedding: { _distance: { to: number[], metric: "l2" | "cosine", sort?: "asc" | "desc" } },
}
```

See [Sorting](/docs/client/sorting) for details, including `_distance` selection of the similarity score.
