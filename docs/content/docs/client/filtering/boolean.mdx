## Operators

| Operator | Description |
|----------|-------------|
| `equals` | Exact match |
| `not` | Negation |

```ts
// Direct value (shorthand for equals)
where: { active: true }

// Negation
where: { active: { not: true } }   // Same as active: false
```

Both operators work the same on every scalar type — see [Filtering](/docs/client/filtering).

## Nullable Booleans

For nullable boolean scalars:

```ts
// Only true
where: { verified: true }

// Only false (not null)
where: { verified: false }

// Only null
where: { verified: null }

// Not null (true or false)
where: { verified: { not: null } }
```

## Combined Conditions

```ts
// Active and not deleted
where: {
  active: true,
  deleted: false,
}

// Published or featured
where: {
  OR: [
    { published: true },
    { featured: true },
  ],
}
```

For the soft-delete pattern (a `deleted` boolean instead of removing rows), see [delete](/docs/client/delete#soft-delete-pattern).
