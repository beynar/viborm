<Callout type="info">
  Array scalars (`s.string().array()`, `s.int().array()`, etc.) work on PostgreSQL, MySQL, and SQLite. PostgreSQL stores them as native array columns; MySQL and SQLite don't have a native array type, so VibORM stores them as `JSON` columns and emulates the same filter and update operators on top of JSON functions (`JSON_CONTAINS`, `json_each`, and similar).
</Callout>

## Operators

| Operator | Description |
|----------|-------------|
| `has` | Array contains value |
| `hasEvery` | Array contains all values |
| `hasSome` | Array contains any value |
| `isEmpty` | Array is empty |
| `equals` | Exact array match |

## has

Check if array contains a single value:

```ts
// Has "featured" tag
where: {
  tags: { has: "featured" },
}

// Has specific role
where: {
  roles: { has: "ADMIN" },
}
```

`has: null` never matches any row on any dialect (SQL `NULL = element` is never true), matching PostgreSQL and Prisma semantics.

## hasEvery

Check if array contains ALL specified values:

```ts
// Has both "tech" and "tutorial"
where: {
  tags: { hasEvery: ["tech", "tutorial"] },
}

// User has all required permissions
where: {
  permissions: { hasEvery: ["read", "write", "delete"] },
}
```

## hasSome

Check if array contains ANY of the specified values:

```ts
// Has "tech" OR "science" OR "programming"
where: {
  tags: { hasSome: ["tech", "science", "programming"] },
}

// User has at least one admin permission
where: {
  permissions: { hasSome: ["admin", "superuser"] },
}
```

## isEmpty

Check if array is empty:

```ts
// No tags
where: {
  tags: { isEmpty: true },
}

// Has at least one tag
where: {
  tags: { isEmpty: false },
}
```

## equals

Exact array match (order matters):

```ts
// Exactly these tags in this order
where: {
  tags: { equals: ["featured", "top"] },
}
```

## Examples

### Tagged Content

```ts
async function getPostsByTag(tag: string) {
  return client.post.findMany({
    where: {
      tags: { has: tag },
      published: true,
    },
  });
}
```

### Multiple Tags

```ts
async function getPostsWithAllTags(tags: string[]) {
  return client.post.findMany({
    where: {
      tags: { hasEvery: tags },
    },
  });
}

async function getPostsWithAnyTag(tags: string[]) {
  return client.post.findMany({
    where: {
      tags: { hasSome: tags },
    },
  });
}
```

### Permission Check

```ts
async function getUsersWithPermission(permission: string) {
  return client.user.findMany({
    where: {
      permissions: { has: permission },
    },
  });
}

async function getUsersWithAllPermissions(permissions: string[]) {
  return client.user.findMany({
    where: {
      permissions: { hasEvery: permissions },
    },
  });
}
```

### Untagged Content

```ts
async function getUntaggedPosts() {
  return client.post.findMany({
    where: {
      tags: { isEmpty: true },
    },
  });
}
```

### Role-Based Access

```ts
async function getAdminUsers() {
  return client.user.findMany({
    where: {
      roles: { hasSome: ["ADMIN", "SUPERADMIN"] },
    },
  });
}
```

## Updating Arrays

```ts
// Add to array
await client.post.update({
  where: { id: "post_123" },
  data: {
    tags: { push: "new-tag" },
  },
});

// Add several values (each appended as its own element)
await client.post.update({
  where: { id: "post_123" },
  data: {
    tags: { push: ["tag-a", "tag-b"] },
  },
});

// Prepend instead of append
await client.post.update({
  where: { id: "post_123" },
  data: {
    tags: { unshift: "first-tag" },
  },
});

// Set entire array
await client.post.update({
  where: { id: "post_123" },
  data: {
    tags: { set: ["tag1", "tag2", "tag3"] },
  },
});
```

## Database Support

<Tabs items={["PostgreSQL", "MySQL", "SQLite"]}>
  <Tab value="PostgreSQL">
Native array columns (`text[]`, `int[]`, etc). `has` uses `= ANY(...)`, `hasEvery` uses the containment operator `@>`, `hasSome` uses the overlap operator `&&`; `push`/`unshift` concatenate with `array_cat`.
  </Tab>
  <Tab value="MySQL">
Array scalars are stored as `JSON` columns. `has` uses `JSON_CONTAINS`, `hasSome` uses `JSON_OVERLAPS`, `isEmpty` checks `JSON_LENGTH`, and `push`/`unshift` concatenate via `JSON_MERGE_PRESERVE`.
  </Tab>
  <Tab value="SQLite">
Array scalars are stored as `JSON` columns (SQLite's `json_*` functions). The same `has`/`hasEvery`/`hasSome`/`isEmpty`/`push` operators are emulated with `json_each` and the `json_*` function family.
  </Tab>
</Tabs>

## JSON Columns as an Alternative

If you need more flexibility than the array operators above (e.g. arrays of objects, or ad hoc JSON structures), you can still model a field as raw JSON and use the [JSON filter operators](/docs/client/filtering/json) instead:

```ts
// Schema
const post = s.model({
  id: s.string().id(),
  metadata: s.json().default([]),
});

// Query with JSON operators (array_contains only matches array values)
where: {
  metadata: {
    array_contains: "featured",
  },
}
```
