---
title: groupBy
description: Group records and compute aggregates per group
icon: Group
---

Group records by one or more fields and compute aggregates per group:

```ts
const byRole = await client.user.groupBy({
  by: ["role"],
  _count: true,
});

// Result:
// [
//   { role: "USER", _count: 100 },
//   { role: "ADMIN", _count: 5 },
// ]
```

## With aggregates

```ts
const stats = await client.post.groupBy({
  by: ["authorId"],
  _count: true,
  _avg: { views: true },
  _sum: { views: true },
});

// [
//   { authorId: "user_1", _count: 10, _avg: { views: 50 }, _sum: { views: 500 } },
//   { authorId: "user_2", _count: 5, _avg: { views: 100 }, _sum: { views: 500 } },
// ]
```

## With filtering

Use `where` to filter rows before grouping, and `having` to filter groups after:

```ts
const stats = await client.post.groupBy({
  by: ["authorId"],
  where: { published: true },
  _count: true,
  having: {
    _count: { _all: { gt: 5 } }, // Only authors with 5+ posts
  },
  orderBy: { _count: { _all: "desc" } },
  take: 10,
});
```

## Options

```ts
await client.post.groupBy({
  by: ["field1", "field2"],  // Group by fields
  where: { ... },            // Filter before grouping
  having: { ... },           // Filter after grouping
  orderBy: { ... },          // Sort groups
  take: 10,                  // Limit groups
  skip: 0,                   // Offset groups
  _count: true | { ... },
  _avg: { ... },
  _sum: { ... },
  _min: { ... },
  _max: { ... },
});
```

<Callout type="info">
  Every `orderBy` field must either appear in `by` or be an aggregate key (`_count`, `_avg`, `_sum`, `_min`, `_max`). Ordering by an aggregate works the same way `having` does:

  ```ts
  await client.post.groupBy({
    by: ["authorId"],
    _sum: { views: true },
    orderBy: { _sum: { views: "desc" } },
  });
  ```
</Callout>

## Examples

### Top authors

```ts
async function getTopAuthors(limit = 10) {
  return client.post.groupBy({
    by: ["authorId"],
    where: { published: true },
    _count: true,
    _sum: { views: true },
    orderBy: { _sum: { views: "desc" } },
    take: limit,
  });
}
```

### Category stats

```ts
async function getCategoryStats() {
  return client.post.groupBy({
    by: ["categoryId"],
    _count: true,
    _avg: { views: true },
    having: {
      _count: { _all: { gte: 1 } },
    },
  });
}
```
