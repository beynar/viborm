---
title: createMany
description: Create multiple records in a single operation
icon: CopyPlus
---

Create multiple records in one call:

```ts
const result = await client.user.createMany({
  data: [
    { email: "alice@example.com", name: "Alice" },
    { email: "bob@example.com", name: "Bob" },
    { email: "carol@example.com", name: "Carol" },
  ],
});
// Result: { count: 3 }
```

`createMany` returns a `{ count }`. It doesn't accept nested relations — for that, use [`create`](/docs/client/create) or [nested writes](/docs/client/nested-writes).

## Skip duplicates

```ts
const result = await client.user.createMany({
  data: [
    { email: "alice@example.com", name: "Alice" },
    { email: "alice@example.com", name: "Alice Duplicate" }, // Skipped
  ],
  skipDuplicates: true,
});
// Result: { count: 1 }
```

On MySQL, `skipDuplicates` can silently skip more than duplicates — see [Compatibility](/docs/client/compatibility#database-differences).

## createManyAndReturn

Same as `createMany`, but returns the created rows instead of a count:

```ts
const users = await client.user.createManyAndReturn({
  data: [
    { email: "alice@example.com", name: "Alice" },
    { email: "bob@example.com", name: "Bob" },
  ],
  select: { id: true, email: true },
});
// Type: { id: string; email: string }[]
```

## Options

```ts
await client.user.createMany({
  data: [{ ... }],      // Required: array of records
  skipDuplicates: true, // Optional: skip constraint violations
});
```
