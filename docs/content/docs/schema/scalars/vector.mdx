<Callout type="info">
  Vector scalars are primarily supported in PostgreSQL with the `pgvector` extension.
</Callout>

## Basic Usage

```ts
import { s } from "viborm";

s.vector()               // Required number[]
s.vector().dimension(3)  // Fixed-length number[]
s.vector().nullable()    // number[] | null
```

## Chainable Methods

```ts
s.vector()
  .dimension(1536)      // Require a fixed vector length
  .nullable()           // Allow NULL
  .default([])          // Default value
  .map("column_name")   // Custom column name
```

## Type Mapping

| Modifier | TypeScript | PostgreSQL | MySQL | SQLite |
|----------|------------|------------|-------|--------|
| `s.vector()` | `number[]` | `vector` | N/A | N/A |
| `.dimension(1536)` | `number[]` | `vector(1536)` | N/A | N/A |
| `.nullable()` | `number[] \| null` | `vector NULL` | N/A | N/A |

## PostgreSQL Setup

Enable the pgvector extension:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

## Examples

```ts
// OpenAI embedding (1536 dimensions)
const embedding = s.vector().dimension(1536);

// Nullable embedding
const optionalEmbedding = s.vector().dimension(1536).nullable();
```

## Complete Example

```ts
const document = s.model({
  id: s.string().id().ulid(),
  content: s.string(),
  embedding: s.vector().dimension(1536),  // Store embedding
  createdAt: s.dateTime().now(),
}).map("documents");

// Store a document with embedding
await client.document.create({
  data: {
    content: "Hello, world!",
    embedding: [0.1, 0.2, 0.3 /* 1533 more values */],
  }
});
```

## Similarity Search

Use `_distance` in `orderBy` for nearest-neighbor searches:

```ts
const queryEmbedding = [0.1, 0.2, 0.3 /* 1533 more values */];

const similar = await client.document.findMany({
  select: { id: true, content: true },
  orderBy: {
    embedding: {
      _distance: {
        to: queryEmbedding,
        metric: "cosine", // "l2" | "cosine"
      },
    },
  },
  take: 10,
});
```

Set `sort: "desc"` to return farthest matches first. You can also select the distance score; it is returned as `_distance: number`:

```ts
const scored = await client.document.findMany({
  select: {
    id: true,
    embedding: {
      _distance: {
        to: queryEmbedding,
        metric: "l2",
      },
    },
  },
  orderBy: {
    embedding: {
      _distance: {
        to: queryEmbedding,
        metric: "l2",
      },
    },
  },
});

scored[0]?._distance; // number | undefined
```

<Callout type="warning">
  Distance ordering and selection require a pgvector-enabled PostgreSQL driver, for example `new PgDriver({ pgvector: true })`. Other drivers throw `FeatureNotSupportedError`, and the query vector length must match `.dimension(...)` when a dimension is declared.
</Callout>

## Indexing Vectors

For efficient similarity search, create an index:

```sql
-- HNSW index (recommended for most cases)
CREATE INDEX ON documents USING hnsw (embedding vector_cosine_ops);

-- IVFFlat index (for very large datasets)
CREATE INDEX ON documents USING ivfflat (embedding vector_cosine_ops)
  WITH (lists = 100);
```

## Distance Functions

| Operator | Function | Use Case |
|----------|----------|----------|
| `\<->` | L2 distance | General |
| `\<#>` | Inner product | Normalized vectors |
| `\<=>` | Cosine distance | Text embeddings |

## When to Use Vector

| Use Case | Recommendation |
|----------|----------------|
| Semantic search | Vector embeddings |
| Image similarity | Vector embeddings |
| Recommendation | Vector embeddings |
| Full-text search | PostgreSQL tsvector or dedicated search |
| Exact matching | Regular scalars with indexes |
