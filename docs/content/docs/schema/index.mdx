## Overview

```ts
import { s } from "viborm";

const user = s.model({
  id: s.string().id().ulid(),
  email: s.string().unique(),
  name: s.string().nullable(),
  posts: s.toMany(() => post),
});
```

## Key Concepts

### The `s` Builder

All schema definitions use the `s` builder object:

```ts
import { s } from "viborm";

s.model({ ... })              // Create a model
s.string()                    // String scalar
s.int()                       // Integer scalar
s.toMany(() => post)          // A collection slot
s.toOne(() => user)           // A singular slot
// ... and more
```

### Chainable API

Every method returns a new instance, enabling fluent definitions:

```ts
s.string()           // Basic string
  .nullable()        // Can be null
  .unique()          // Unique constraint
  .default("value")  // Default value
  .map("column_name") // Custom column name
```

### Type Inference

Types are inferred automatically from your schema:

```ts
const user = s.model({
  id: s.string().id(),
  email: s.string(),
  age: s.int().nullable(),
});

// Inferred type:
// { id: string; email: string; age: number | null }
```
